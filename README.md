# 苏州中考英语听说 · 开箱即用模拟评测

面向**苏州市九年级中考英语听力口语自动化考试**（30 分）的开源练习工具。
打开网页就能用，**不用注册、不用付费、不用配置任何账号**。

---

## 怎么用（三步）

### 第一步：拿到工具

```bash
git clone https://github.com/Andy-Xie-1145/open-suzhou-english-listening-speaking.git
cd open-suzhou-english-listening-speaking
npm install
npm run dev
```

浏览器会打开一个地址，形如 `http://localhost:5173`。

> ⚠️ 必须是 **HTTPS 或 localhost**。双击 html 文件直接打开不行——
> 浏览器只在安全上下文里给麦克风权限，这是浏览器策略。

### 第二步：打开就是一份完整卷

打开页面会看到：

```
第三题 朗读短文        ← 当前题，显示全文与建议用时
朗读 2 分 00 秒 / 问答 1 分 30 秒 / 话题 2 分 30 秒

[朗读短文]  [情景问答]  [话题简述]     ← 三个题型用标签页切换

它把整张卷面给你看：本次抽到了哪篇朗读、哪两道问答、哪个话题，
以及每题建议用多久。点击「换一套卷」会重新抽题，且**不会重复上一套**。

### 第三步：答题

两种方式，任选：

| 方式 | 怎么做 | 需要配置 |
|---|---|---|
| **手动输入**（默认） | 在文本框写下你朗读/说的内容，点「评分（近似）」 | **什么都不用配** |
| 录音自动转写 | 点「开始录音」→ 说完点「结束并评分」 | 需加载语音转写模型 + 麦克风 |

**首次使用建议直接从手动输入开始** —— 零配置，评估结果完全相同。

评分后：

- 每个题型**单独出分**，分数旁标有「近似分」和「近似模拟」
- 朗读题会**逐词标出漏读了哪些词**、哪些词可能读错
- 情景问答会**逐条列出哪个要点没覆盖、哪些说法没命中**
- 话题简述会明确告诉你**说了几句、是否达到 7 句硬门槛**

点顶部的标签页切到下一个题型继续。

## 完整考场流程

本工具的流程与江苏中考听力口语自动化考试一致：

```
考前30min  准备室：签到 + 考前培训
考前15min  候考室待考
考前10min  [准备考试] 系统加载试卷
考前 5min  进考场、核对准考证
           设备测试 → 等待考试开始
开考时刻   倒计时 → 正式开始
考生实际作答 22 分钟 = 听力 12 + 口语 10
交卷
```

考场纪律同样遵循：**开考后不得进入考场，考场内不得中途退出**。

## ⚠️ 必须先读：这是一条红线

**本工具输出的是近似模拟结果，不是苏州市中考听力口语考试的评分。**

| | |
|---|---|
| 真实评分由 | 讯飞承建的引擎完成，算法不对外 |
| 本工具 | 无法复刻，也不试图等同 |
| 能回答的问题 | 「我漏读了哪些词、哪些词可能读错、语速是否合适」 |
| 不能回答的问题 | 「我在中考能得多少分」 |

### 本工具做不到的事

- **不评估音素级发音错误**：把 th 读成 s 这类替换检测不到
- **不评估语调与韵律**：教辅明确考察「突出语调」，本工具完全未做
- **转写会掩盖错读**：语音转写引擎可能把读错的词自动纠正成正确拼写
- **要点覆盖靠英文关键词判定**：词表之外的说法会被漏判
- **听力两节未做**：真实考试音频受版权与保密限制拿不到

### 各项权重都是假设值

官方只公布「满分 30 分」，**各题型分值、各维度权重均未公开**。
本项目使用的权重（完整度 0.70 / 准确度 0.20 / 流利度 0.10 等）是**自行假设**，
依据是教辅机构转述的「完整度占七成」，方向上与之致，具体比例无从核实。
完整清单见 [SPEC 第 7 节](spec/suzhou-listening-speaking.spec.md#7-需要核实但当前无法核实的事项)。

> **对外使用时请原样保留以上两节。**

## 已实现的题型

| 题型 | 考法 | 状态 |
|---|---|---|
| Q3 朗读短文 | 封闭题，有标准原文 | ✅ 完整闭环 |
| Q4 情景问答（2 题） | 半开放题，情境类别配平 | ✅ 完整闭环 |
| Q5 话题简述 | 开放题，**必须说满 7 句** | ✅ 完整闭环 |
| Q1/Q2 听力两节 | 客观题 | ❌ 未做（音频不可得） |

### 各题型的近似评分

| 题型 | 判定维度 | 特点 |
|---|---|---|
| Q3 朗读 | 完整度 / 准确度 / 流利度 | 有原文，**逐词比对**，能指出漏读了哪几个词 |
| Q4 情景问答 | 回应问句 / 要点覆盖 / 表达量 / 流利度 | 半开放，**逐条列出哪个要点没覆盖、哪些说法没命中** |
| Q5 话题简述 | 句数 / 要点覆盖 / 逻辑连接 / 流利度 | 开放题，7 句是**硬门槛**，不够直接判不合格 |

## 开箱即用：默认什么都不用配

打开就能用的部分：

- **朗读短文**：手动输入你读的内容，立即得到逐词反馈
- **情景问答**：同上
- **话题简述**：同上

可选增强（**不配也不影响使用**）：

| 增强项 | 作用 | 不配置的后果 |
|---|---|---|
| 语音转写模型（Whisper） | 录音后自动转成文字 | 手动输入，评估结果完全相同 |
| 麦克风 | 录自己的声音 | 手动输入，评估结果完全相同 |
| LLM key | 额外的语法/逻辑建议 | 无此项，其余反馈照常 |

### 如果你想配置语音转写

页面点「加载语音转写模型」，选规格后等待下载：

| 规格 | 体积 | 适用 |
|---|---|---|
| tiny | 约 40 MB | 最低配置设备 |
| **base** | 约 80 MB | **推荐** |
| small | 约 250 MB | 性能好的设备 |

模型**首次下载后会被浏览器缓存，之后离线可用**。

### 如果你想配置 LLM（可选）

智谱 GLM 的 `glm-4-flash` **永久免费且无 token 限制**，是最省事的选择：

1. 在 <https://open.bigmodel.cn> 注册，创建 API Key
2. 粘贴到页面「AI 教练设置」
3. 点「测试连接」

key 存在**你自己浏览器的 localStorage**，只发给你选的服务商，不经过本项目任何服务器。

## 出问题先看这里

页面底部有**真机自检**，点一次就能知道哪一环不通：

```
运行环境 → 麦克风授权 → 音频采集 → 录音解码
        → WASM 运行时 → 模型加载 → 转写产出文本
```

每环独立报告，**失败会给出可执行的补救步骤**（权限被拒、无麦克风、设备被占用、
非安全上下文、下载中断、内存不足等各自不同）。

> 自检结果只反映**你的浏览器**能否工作，与评分质量无关。

## 架构

### 核心约束：服务端开销趋近于零

这是架构硬约束（见 [ARCHITECTURE.md](ARCHITECTURE.md) 第 1 节）：

| 成本项 | 承担方 |
|---|---|
| 语音转写（Whisper ONNX） | **你的浏览器** |
| 音素识别（wav2vec2 ONNX） | **你的浏览器** |
| G2P（espeak-ng WASM） | **你的浏览器** |
| 规则层 | **你的浏览器**，纯 TypeScript 零推理 |
| 音频存储 | **无人**，不出浏览器，用完即弃 |
| LLM 建议 | **你**（自带 key，浏览器直连服务商） |
| CDN + 域名 | 项目维护者（唯一真实支出） |

**音频完全不出本机** —— 对面向未成年人的产品，这比省钱更重要。

### 分层与降级

```
L3  LLM      自带 key        → 语法/逻辑建议
L2  ASR      Whisper ONNX    → 转写文本
L1  音素     wav2vec2 ONNX   → 逐音素对照（规划中）
L0  规则     纯 TypeScript  → 漏读/要点/句数/流利度
```

**任何一层缺失，产品都必须仍能给出 L0 反馈。** 降级是正常路径，不是故障。

### 目录结构

```
src/rules/      L0 规则层        纯 TS，零依赖
src/suzhou/     苏州题型专用      编排、评分、声明文案
src/engine/     引擎层            录音、转写、BYOK
src/ui/         界面
data/           语料
spec/           规格文档
tests/          测试
```
