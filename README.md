## 它能帮你做什么

考前想练，但不知道问题出在哪 —— 这是它想解决的事。

- **朗读短文**：读完告诉你漏读了哪几个词、哪些词可能读错、语速快不快
- **情景问答**：告诉你该回答的两点里漏了哪点、问句里的关键词有没有接住
- **话题简述**：告诉你说了几句、有没有达到 7 句的硬要求、有没有跑题

它做的事就一件：**把一整套卷子摊在你面前，像真的考试那样做一遍，
然后告诉你具体哪里没做好**，而不是只给一个分数。

### 它不能告诉你「你在中考能考多少分」

这一条必须说清楚。

真实考试的评分由承办方完成，算法不对外，本工具没有、也不可能有。
所以：

| | |
|---|---|
| 能回答 | 「我漏读了哪些词、哪些要点没说、说了几句」 |
| 不能回答 | 「我在中考能考多少分」 |

本工具的所有结果都标着「**近似模拟**」，不会让你误以为是真实分数。
它更像一个陪练，能反复指出具体毛病，但不能替你决定分数。

## 现在怎么开始

### 打开网页就能用

    https://openels.pages.dev

已经上线了。听力音频（1.5 MB）也已经在包里，开考前会自动下完，
考试中只播不下载。

自定义域名 `openels.bbroot.com` 正在等域名解析生效，
生效后会自动指向同一个站点。

### 也可以从源码跑

给想改代码或离线用的人。

**你需要先装 [Node.js](https://nodejs.org) 22 或更高版本**，然后：

```bash
git clone https://github.com/Andy-Xie-1145/open-suzhou-english-listening-speaking.git
cd open-suzhou-english-listening-speaking
npm install
npm run dev
```

浏览器会打开一个地址，形如 `http://localhost:5173`。

> **不要直接双击 index.html 打开** —— 浏览器只在安全上下文里给麦克风权限，
> 这是浏览器的规定，不是本工具的限制。用上面的地址打开就没问题。

### 第一次用，先别急着录音

打开页面默认是**手动输入**：把你朗读或说的内容敲进文本框，点评分即可。
**什么都不用配置，不需要麦克风，不需要下载任何模型。**

评分效果和录音自动转写完全一样，只是一个要打字一个要说话。

想用录音再往下看。

## 想用录音自动转写（可选）

1. 页面点「加载语音转写模型」
2. 选一个规格，等它下载完
3. 允许浏览器使用麦克风
4. 之后录音就能自动转成文字

| 规格 | 大小 | 适合 |
|---|---|---|
| tiny | 约 40 MB | 配置比较差的设备 |
| **base** | 约 80 MB | **推荐** |
| small | 约 250 MB | 设备比较好的 |

模型**只下第一次**，下完会被浏览器缓存，之后离线也能用。

> 录音默认**只在你自己的设备上处理，不上传**。
>
> 代码里已经有一个可选的「云端转写」（识别更准，用的是 Groq 的 whisper-large-v3），
> 但它**默认关闭**，要你自己填 key、自己打开，界面上会写明录音会发给哪家服务商。
> 不开就完全走本地，录音不出设备。
>
> 另外直连 Groq 在国内会被拦（403），要用需要自己配一个反代地址。

## 卡住了？先点页面底部的「真机自检」

点一次就能知道是哪一环不通：

```
运行环境 → 麦克风授权 → 音频采集 → 录音解码
        → 语音模型加载 → 转写产出文本
```

每一环单独报告，失败了会直接告诉你**该怎么办**
（权限被拒 / 没有麦克风 / 设备被占用 / 网络中断 …… 原因各不相同，对策也不同）。

## 开发者

### 环境

Node.js 22+（项目用 `node --experimental-strip-types` 直接运行 TypeScript，不走编译）。

```bash
npm install
npm run typecheck      # 类型检查（含 functions 独立 tsconfig）
npm run test:all       # 全部 23 个测试套件
npm run build          # 产出纯静态文件到 dist/
npm run audio:check    # 报告哪些听力音频需要重新渲染
npm run audio:build    # 构建期渲染听力音频（需先 cd scripts && npm install）
```

### 目录

```
src/rules/      L0 规则层       纯 TS，零依赖
src/suzhou/     苏州题型专用     编排、评分、听力子结构、音频计划
src/engine/     引擎层           录音、转写、ASR 提供方路由、BYOK
src/materials/  语料加载         通用题库（旧结构，Suzhou 编排不依赖它）
src/ui/         界面
data/           语料
scripts/        构建期脚本（听力音频渲染）
spec/           规格文档
tests/          测试
functions/      Cloudflare Pages Function（同源模型代理，当前未启用）
```
