## 2. 严重缺陷修复：E2-08 Q2 考点（报告 §1）

**致缺陷要素**：考点前半把 `mine` 绑定到**提问者**（同桌）的跳绳，紧接着的答语 `No, mine is shorter than yours.`
却沿用问句人称——在该绑定下该句表达的是「同桌的绳比考生短 = 考生的更长」＝ **Yes 分支**。
于是 **Yes 分支的陈述被挂在 `No,` 标签下**，且考生按示例作答会把自己的绳说成 `yours`，角色方向整个反掉。

**改后**：

> `**考点`：比较级 longer + than；问句中 your 指考生手里的跳绳、mine 指同桌的跳绳；答语先作 Yes/No 应答，人称随答语人切换到考生视角（考生自己的绳用 mine、同桌的绳用 yours）：Yes, it is. Mine is longer than yours. / No, it isn't. Yours is longer than mine.（两支的 mine/yours 方向相反，勿写反；两绳一样长也属 No 分支，答 No, it isn't. Mine is as long as yours.）

**分支逻辑逐条代入复核**（考生视角：自己的绳 = `mine`，同桌的绳 = `yours`）：

| 分支 | 应答 | 重述 | 重述含义 | 与标签是否一致 |
|---|---|---|---|---|
| Yes | Yes, it is. | Mine is longer than yours. | 我的比你的长 ＝ 考生绳更长 | ✔ 一致 |
| No（严格更长） | No, it isn't. | Yours is longer than mine. | 你的比我的长 ＝ 考生绳不长 | ✔ 一致 |
| No（等长） | No, it isn't. | Mine is as long as yours. | 一样长 ＝ 考生绳不比对方长 | ✔ 一致 |

**对报告建议文本的两处主动偏离**（均为复核后发现报告文本自身仍有瑕疵，非照抄）：

1. 报告原文用「**问句中 your…、mine 指…**」未标语境边界，读者易把前半的 `mine=同桌` 误套到后半答语上。
   改为 `问句中 your…`，把问句框架与答语框架显式切开。
2. 报告的 No 分支只给「严格更长」一种重述，**遗漏了等长**这一同样属于 No 的合法情形，模板仍不完整。
   补 `Mine is as long as yours.` 兜底（与 E2-04 Q1 的双 No 变体处理方式一致）。

**假修复自检**：字符串 `No, mine is shorter than yours.` 已从全文消失（程序校验 `仍存在=false`），
两个分支各自自洽，人称方向随答语人切换 ✔。

**情景提示未改且否分支仍可达**：`借你的跳绳一起用` 不预设绳的长短，No 分支（考生这条不比同桌的长）与情景相容 ✔。
**同组 Q1 未受影响**：`May I use your stopwatch?` 的 `I=同桌`、`your=考生` 与答语 `I'm using it now.` 本就正确，不动 ✔。

### 3.2 E2-04 Q1 考点（报告 §2.2）

**致缺陷要素**：极性问句要求「先 Yes/No、再重述」两步，却只示范 Yes 分支；
而否分支的重述**不能套同一模板**（不能说 `later than`），阅卷无对应参考。

**改后**（保留前段语法讲解，补齐否分支并说明比较形式随分支改变）：

> `**考点`：比较级 later + than 的省略比较结构（than you did last term）；答语先作 Yes/No 应答，再用含比较结构的完整句子重述，两个分支都给、比较形式随分支改变：Yes, I do. I go to bed later now than I did last term. / No, I don't. I go to bed at about the same time as I did last term. 或 No, I don't. I go to bed earlier than I did last term.（两支不可套同一模板）

**复核**：否分支两个变体均为完整、可直接判分的句子；
`at about the same time as`（等长）与 `earlier than`（更早）**确实不同于** Yes 支的 `later than`，
正好补上原考点漏掉的判分点；`No` 标签下不再出现 `later than` 自相矛盾 ✔。
**对报告文本的一处主动偏离**：报告作 `at about the same time now as I did last term`，
`at about the same time now` 读来别扭（`now` 与 `the same time` 冗余冲突），删去 `now`；
并**补 `earlier than` 变体**——`No, I don't` 在逻辑上涵盖「一样晚」与「更早」，报告文本只覆盖前者。
**同组 Q2 未动**：其 `**考点**` 本已自带 `Yes, I must. / No, I don't have to.` 双分支 ✔。

**复核**：`your home` 由 `you`（＝考生）锚定，**不预设任何客观场所存在**（没有考生没有家）；
释义改回 `考生自己的家`，与被指对象对齐；示例补 `than my home` 成为真正完整比较句，
并显式标注答语人称切换（your → my），与 E2-05 Q2、E2-10 Q1 的既有写法一致；
