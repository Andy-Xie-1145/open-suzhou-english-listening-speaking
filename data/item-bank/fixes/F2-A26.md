## 四、③ 我自己引入又修掉的缺陷（如实记录）

**经过**：我写 A26-05 的新对话时，第一轮用了 `Boy:`、第三轮用了 `Girl:`。
**发现**：跑 `speaker-gate` 时**报了 FAIL、退出码 1**：

```
## A26-05 车间一次进八个人   学生标签 Boy / Girl：第二个学生标签出现在非学生说话人之后
（说话人顺序：Boy -> Mr. Dai -> Girl）
SPEAKER_EXIT=1
```

**处置**：立刻把第三轮改为 `Boy:`，重跑闸门 **PASS / EXIT=0**。

**我要记的不是「我犯了个错」，是这一条**：
**A 类一道题里学生标签只能有一个**——这是 speaker-gate 的 STUDENT-SWITCH 项，它抓到了。
**如果我不跑这道闸门，这道题会以「Boy 开头、Girl 中途」的形态直接归档**，
而五道闸门里只有这一道能看见它。**闸门不是形式，是唯一能兜住这种错的手段。**
