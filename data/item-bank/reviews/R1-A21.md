### 修复约束（**不计入缺陷计数，但必须在修复时一并处理**）

**按 _COMMON §4「处方不完整时，『照做』不等于修复」，本条是给修复方的强制项。**

若只把严重 1–10 的答案字母改正，得到的新序列为：

```
C B C B C B B B B B C C C B D
```

对它跑 1.8 全部检查，结果是：

| 检查项 | 实测 | 结果 |
|---|---|---|
| 周期 p=1…7 | 全部 False | ✓ |
| **最长连续相同** | **5**（第 6–10 位连续五个 B） | **✗ 违反「不大于 2」** |
| 字母次数 | B=8、C=6、D=1 | 严重偏斜 |
| **是否有字母零次** | **A 一次都没做答案** | **✗ 违反「不得有全批一次都不作答案的字母」** |

**因此修复不能是「把 10 个字母改对」这么简单。** 正确做法：先按材料定出 15 题各自唯一正确的选项字母（A21-01 C、A21-02 B、A21-03 C、A21-04 B、A21-05 C、A21-06 B、A21-07 B、A21-08 B、A21-09 B、A21-10 B、A21-11 C、A21-12 C、A21-13 C、A21-14 B、A21-15 D），然后**通过调整选项顺序**把答案序列重排到同时满足：最长连跑 ≤2、A/B/C/D 四字母都用上、任一字母占比不过高（建议 ≤5/15），最后让末尾汇总行与 Answer 行逐位一致。

**关键：正确的做法是调换选项的行序，而不是改材料。** 这 15 题的材料与选项本身经我逐条核验全部成立（45 个干扰项全是甲档），**唯一需要动的只有 Answer 字母和选项行序，材料正文一个字都不用改**。

**一项有代价的做法及其代价（按 _COMMON §4「采用了有代价的做法，必须把代价一起交上来」）**：调换选项行序会改变每题四个选项的呈现顺序，学生看到的选项字母与原卷不同。代价是**A21 的选项字母与出题时的意图不再一一对应**；该代价**可逆**（保存原行序即可回退）；**建议只在必须重排时才动**，且重排后必须重跑本题报告第 5 节的全套 1.8 检查。

## 9. 规约未覆盖，建议补条款

**（1）「标题与材料不符」缺条款。**
本批 A21-05 的标题写「四十升」而材料写「Fifty litres」。REVIEW-RUBRIC 1.2 管的是**材料内部**的自洽，1.6 管的是结构标记，1.7 管的是重复与主题范围，**没有任何一条覆盖「## 编号 标题 里的数字/事实与材料不符」**。我按最接近的 1.2 记了中等，但这是借条款，不是条款本身覆盖。
**建议在 1.6 增一条：「## 标题行中出现的数字、时间、数量必须与材料一致；标题数字在材料中不存在或与材料相矛盾 → 中等」**。这条对本项目很实用：A 类标题普遍带数字（如「打印一页两毛钱」「打车八公里二十元」「课间操要做五分钟」），一旦材料数字微调，标题极易失配。

**（2）建议给流水线增加一道「答案键与材料一致性」的机械核对。**
本批 10/15 的答案错，**而现有门禁一条都没报出来**：wordcount-gate 只管词数与结构，encoding-check 只管字节，topic-guard 只管语义重复，而 1.8 排列检查在错误答案上照样 PASS（本批即是如此）。也就是说，**目前没有任何一个自动环节能发现答案键与材料矛盾**——全靠人工逐题读。这正是本批被拦下来的唯一原因。
建议调度方考虑：增加一道「Answer 行的字母所指选项，其关键信息必须能在材料里找到」的半自动核对（可先用选项文本与材料的词元重合度粗筛，再人工确认）。**我不主张由审核员加严判定，也不主张改规约；这是工具缺口，不是判分标准缺口。**

**（3）超纲词（1.3）仍无法机械判定。**
承前三轮：仓库内无课标五级词表。本轮同样**不据此判任何词超纲**。待核词新增：**frost（霜）、tug of war（拔河）、bookmark（书签）、service hall（营业厅）、litres、top up（充值）、colour（英式拼写，与库内用法一致）**。建议补词表。

**（4）topic-guard 自匹配假阳性（第四次记录）。**
A21 已 build 进索引，15 题各与自身 1.000，脚本 VERDICT 恒为「有超阈值相似项」、退出码恒为 1。**连续第四批出现同一现象，建议尽快让脚本跳过「同文件且同 id」的自匹配。**
