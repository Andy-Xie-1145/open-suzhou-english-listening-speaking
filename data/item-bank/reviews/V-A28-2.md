## 三、抽查一：A28-01「看成分标签才知道缩不缩」

**这一处是 R2 没给处方、我（writer-bcd）在 task-63 自行设计并说明依据的改动。按调度方要求，我回原文自己判断，既不预设它错、也不采信它。**

当前短文：
```
Girl: Ms. Fu, how do I know if this shirt will shrink?
Ms. Fu: Read the label inside. Cotton shrinks, pure linen does not.
Girl: The label says sixty percent cotton. Is that bad?
Ms. Fu: Ask for a hundred percent linen if you can wash it often.
```

**改前的病**：`Cotton shrinks, cotton and linen does not.` —— **「cotton and linen」含棉**，
若棉会缩，含棉的混纺也必会缩，这一句自相矛盾。R1 判它中等，判得成立。

**我的独立判读**：

| 检查 | 结论 |
|---|---|
| 改后是否自洽 | **自洽**。「pure linen」不含棉 ⇒ 不缩。 |
| 与后两句是否一致 | **一致**。女孩说 `sixty percent cotton`（含棉，会缩）→ Ms. Fu 让她要 `a hundred percent linen`，而 **hundred percent linen ＝ pure linen**，两处互证而非互斥 |
| 语法 | 通顺 |
| 答案 B 及其依据 | `Read the label inside the shirt.` ← `Read the label inside.`，**一字未动** |
| 唯一性 | 成立。四个干扰项逐一可排除（见下表） |
| 是否引入新问题 | **未引入** |

**四选项逐一（判档只问：材料里有没有一句直接针对这个选项的话？）**：

| 选项 | 文本 | 材料里有没有**一句直接针对它**的话 | 档 |
|---|---|---|---|
| A | Wash it at home first. | **有**：`Read the label inside.` 是规定的查明办法，材料把「先洗了再说」这条路径排除在外（末句的 `if you can wash it often` 是**决定布料之后**的许可，不是查明手段） | **甲** |
| **B** | **Read the label inside the shirt.** | **有**：`Read the label inside.` 直接给出 | 正确项 |
| C | Buy two and keep the better one. | **有**：`Read the label inside.` 一句话就把「靠买来做比较」否掉 | **甲** |
| D | Wait until it shrinks. | **有**：同上，材料给的是看标签而不是等它缩 | **甲** |

**四档合计：正确项 1 ／ 甲 3 ／ 乙 0 ／ 丙 0 ／ 丁 0。**

**一条观察（不判缺陷）**：短文里 `pure linen` 与 `a hundred percent linen` 是同一物的两种说法。
学生可能一瞬间要确认两者是不是一回事——**它们是同义词，且这个重复正好互相加固，不构成歧义**。

**判定：A28-01 合格。这一处自行设计的改动，我回原文核过，理由成立。**
