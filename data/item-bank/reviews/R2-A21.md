## 4. 本轮唯一的流程发现：**F1-A21 漏报了一处 A21-03 的改动**

- **位置**：修复记录 `fixes/F1-A21.md` 的 §2（逐条修复记录）与 §9（修复覆盖清单）
- **事实**：当前磁盘上的 A21-03 是

  ```
  - A. Ten yuan. / - B. Sixteen yuan. / - C. Twenty-six yuan. / - D. Twenty yuan.   **Answer** D
  ```

  而 R1-A21 §3 的逐题表第 81 行逐字记载：**A21-A21 原文件的 Answer 是 C**。我穷举了四个选项文本的全部排列、逐一与基线 MD5 比对，**唯一命中基线的是**：

  ```
  - A. Ten yuan. / - B. Sixteen yuan. / - C. Twenty yuan. / - D. Twenty-six yuan.   **Answer** C
  ```

  也就是说：**A21-03 被重排了选项、Answer 字母由 C 改成了 D**。
- **但 F1-A21 的 §2（12 条）与 §9（14 行清单）都没有列 A21-03**——§9 的第 1 至 12 行覆盖 A21-04／05／06／07／08／10／11／12／13／15 与汇总行，第 13、14 行是两条标题，**唯独没有 A21-03**。
- **为什么这是问题**：R1-A21 **并未把 A21-03 列为缺陷**（其 §3 表第 81 行判为「一致」）。因此这处改动**既不在授权范围内，也不在缺陷清单内**。后果是：§6 那条「除授权改动外零字节改动」的证明**表面成立、实质不可复现**——**按 §9 清单逐条复审的审核员会漏掉它、算不出基线 MD5**（我第一次就是这么撞上的：14 组全部命中、26 行不同、MD5 对不上）。这正是 R2 这一轮要抓的东西。

- **为什么定中等而非严重**：受损的是**修复记录的可追溯性**，不是题目内容，也不是判分有效性。
- **建议补记**：F1-A21 应在 §9 增第 15 行——「A21-03 选项行重排（C→D），R1 未列为缺陷，属**计划外改动**；改动后内容正确，建议在记录中说明动机（例如与其他题统一序列分布），或回退。**回退成本为零**（四个选项顺序复原、Answer 改回 C），但**回退会改变答案序列**，需重跑 1.8——这一点请调度方裁决。
