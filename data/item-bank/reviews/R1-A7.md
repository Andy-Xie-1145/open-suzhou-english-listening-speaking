  `there is no train on Sunday` 与 `Today is Saturday` 两条信息**在逻辑上不能推出**「所以坐公交」——正因为今天是周六，火车恰恰是可用的。末轮的 `Then` 属非逻辑连接词。
- **为什么是问题**：派单必查项 2 要求「每个错误选项都必须能用材料中的一句原文排除」。选项 C「By bus on Sunday.」目前只能靠第 83 行 `Today is Saturday` 排除；若学生把 `Today is Saturday` 读成「今天是周六（即明天是周日），我打算周日去」，则 C 会被判为合理答案，**答案唯一性被削弱**。当前仍可由末轮 `Then I take the bus` 直取答案 B，故不判严重，判中等。
- **建议改法**（改材料使因果成立；已用脚本逐行复算，**第 82 行 15 词→15 词，第 83 行 9 词→7 词，本段 53 → 51（−2），仍在限内**）：
  - 第 82 行改为（15 词，与原行等长）：`Man: Yes. It leaves from the north station, but it does not run on Saturdays.`
  - 第 83 行改为（7 词，−2 词）：`Boy: Saturday. Then I take the bus.`
  - 改后：材料明示「周六不开火车」+「今天是周六」⇒ 坐公交，因果闭合；选项 C「By bus on Sunday.」与 D「By train on Sunday.」改由 `does not run on Saturdays` 与「Sunday ≠ Saturday」排除，排除依据反而比原文更直接。

### M4. A7-12 材料未交代「our class」是哪一班 —— 材料前提不完整
- **位置**：A7-12，第 203–204 行
- **问题原文**：
  - 第 203 行 `Boy: Ms. Pei, who is our class playing in the football final?`
  - 第 204 行 `Ms. Pei: Class Two against Class Five. The match starts at three on Friday.`
  男生说的是 `our class`，但**全段从未说明本班是 Class Two 还是 Class Five**。若本班是 Class Five，对手应为 Class Two，而该选项**未出现在四个选项中**。
- **为什么是问题**：正确答案 C 的成立依赖一个材料从未陈述的隐含前提（「先说的 Class Two 就是我们的班」）。这是派单必查项 2 的「答案可由材料推出」要求的缺口。当前因四个选项中只有 Class Five 在材料里作为队伍出现，学生仍能靠排除法唯一命中，故**不判严重，判中等**。
- **建议改法**（补明前提，**+3 词 → 51 → 54，仍在限内**，同时顺带修掉轻微 L1 的问法问题）：
  - 第 203 行改为：`Boy: Ms. Pei, our class is Class Two. Who do we play in the final?`（14 词，原 11 词）
  - 改后材料自洽，且四个选项 Class One / Three / Five / Six 的排除依据完整。
