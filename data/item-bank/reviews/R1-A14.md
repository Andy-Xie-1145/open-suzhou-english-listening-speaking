## 3. 答案排列实测（1.8 / _COMMON §2c，四项全部写数字）

答案序列（实测）：`C A B D B A C D B A D C B A C`

**(1) 周期检测**——检测范围为**所有不超过序列长度一半的周期**，n=15，故 p=1～7（不只 2～6）：

| p | 是否满足 seq[i]==seq[i+p]（i=1…n−p） | 首个反例 |
|---|---|---|
| 1 | 否 | i=1：C ≠ A |
| 2 | 否 | i=1：C ≠ B |
| 3 | 否 | i=1：C ≠ D |
| 4 | 否 | i=1：C ≠ B |
| 5 | 否 | i=1：C ≠ A |
| 6 | 否 | i=2：A ≠ D（i=1 恰好 C=C，**不能据此判过**） |
| 7 | 否 | i=1：C ≠ D |

结论：**无周期**。

**(2) 前半段与后半段是否互为重复**：n=15 为奇数，无严格对半划分。作为最接近的近似判读：前 7 项 `C A B D B A C` 与后 8 项 `D B A D C B A C` 逐位比较，8 个位置里 3 个相同、5 个不同，**不构成互为重复**。

**(3) 最长连续相同**：相邻两两比对，15 项中**没有任何一对相邻相同**，最长连续相同 = **1**（要求 ≤2，合格）。

**(4) 各字母作为正确答案的次数**：A = **4**（第 2、6、10、14 题）｜B = **4**（第 3、5、9、13 题）｜C = **4**（第 1、7、12、15 题）｜D = **3**（第 4、8、11 题）。合计 4+4+4+3 = 15，与题数一致。**无全批一次都不作答案的字母。**

**(5) 逐题位置偏斜（1.8b）**：A 类每题只有一个答案位置，不存在 1.8b 的 ①②③ 空位偏斜；就答案字母集中度看，15 题分布 4/4/4/3，最大占比 4/15 = 26.7%，远低于 70% 判缺陷线。

**一项如实记录的观察（不判缺陷）**：序列第 5-6、9-10、13-14 位出现三处 `BA` 二元组（间隔恒为 4）。但严格的 p=4 周期检测在 i=1 处即失败（C ≠ B），不满足 1.8「前 (n−p) 项均满足」的定义。**REVIEW-RUBRIC 未覆盖「局部二元组复现」这一形态，按任务书「不要自行加严」的要求，此处只记录、不判缺陷、不计入任何计数，并提请规约考虑是否补条款。**
