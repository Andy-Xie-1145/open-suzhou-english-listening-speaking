**严重 1｜A27-11 答案错（C 应为 B）—— 答案错**
- **位置**：A27-11 Answer 行

**严重 2｜A27-12 答案错（B 应为 A）—— 答案错**

### 修复约束（**不计入缺陷计数，但必须在修复时一并处理**）

**按 _COMMON §4「处方不完整时，『照做』不等于修复」，本条是给修复方的强制项。**

若只把严重 1–4 的答案字母改正，得到的新序列为：

```
D B A C B D C A D A B A C C C
```

对它跑 1.8 全部检查：

| 检查项 | 实测 | 结果 |
|---|---|---|
| 周期 p=1…7 | 全部 False | ✓ |
| **最长连续相同** | **3**（第 13–15 位连续三个 C） | **✗ 违反「不大于 2」** |
| 字母次数 | A=4、B=3、C=5、D=3 | 尚可 |

| 最高频占比 | 5/15 = 33.3% | ✓ |

**因此修复不能只是「把 4 个字母改对」。** 正确做法：先按材料定出 15 题各自唯一正确的选项字母（A27-01 D、A27-02 B、A27-03 A、A27-04 C、A27-05 B、A27-06 D、A27-07 C、A27-08 A、A27-09 D、A27-10 A、**A27-11 B、A27-12 A、A27-13 C、A27-14 C**、A27-15 C），然后**通过调整选项行序**把答案序列重排到：最长连跑 ≤2、四字母都用上、任一字母不超过 5/15，最后让末尾汇总行与 Answer 行逐位一致。

**关键：正确的做法是调换选项行序，而不是改材料。** 这 15 题的材料与选项经我逐条核验全部成立（45 个干扰项 100% 甲档），**唯一需要动的只有 Answer 字母、选项行序，以及 6 处说话人标签；材料正文一个字都不用改**。

**一项有代价的做法及其代价（按 _COMMON §4）**：调换选项行序会改变学生看到的选项字母，与出题时的意图不再一一对应。该代价**可逆**（保存原行序即可回退）；**建议只在必须重排时才动**，重排后必须重跑本报告第 5 节的全套 1.8 检查。
