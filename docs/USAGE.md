# 使用指南

## 一分钟上手

1. 用 Chrome / Edge 打开项目地址（WebGPU 支持最佳）
2. 点击「开始练习」选择题型
3. 录音 → 提交 → 立即看到反馈

**不需要注册，不需要付费，不需要 API key 也能用** —— L0 规则层开箱即用。

---

## 功能与降级

本工具按能力自动降级。下表说明你当前能看到什么：

| 你的情况 | 你能得到的反馈 |
|---|---|
| 全新用户，什么都没配置 | 听力判分 + 朗读漏读/误读定位 + 句数/覆盖/连接词 |
| 加载了音素模型 | 追加：逐音素对照（应为 /x/ → 实际 /y/） |
| 加载了 Whisper | 追加：自动转写，不用手打 |
| 配置了 LLM key | 追加：逻辑评价、语法建议、个性化提示 |

**任何配置缺失都不会让页面出错**，只是反馈粒度递减。

---

## 配置 LLM（可选）

进入「设置 → AI 增强」，选择一个服务商，粘贴你的 API key。

### 推荐：智谱 GLM（永久免费）

1. 打开 https://open.bigmodel.cn 注册
2. 进入「API Key 管理」，新建一个 key
3. 复制粘贴到本工具
4. 点击「测试连接」

GLM-4-Flash **永久免费且无 token 限制**，是国内用户最容易上手的选择。

### 其他选择

| 服务商 | 获取 key | 免费情况 |
|---|---|---|
| 硅基流动 | siliconflow.cn | 有完全免费模型 |
| Groq | console.groq.com | 免费额度高 |
| Google AI Studio | aistudio.google.com | 免费额度 |
| Ollama | 本地安装 | 完全离线 |

### 关于你的 key

- 存在**你自己浏览器的 localStorage** 里
- 只发给你选择的服务商，不经过我们的任何服务器
- 不上传、不记录、不共享
- 随时可以点「清除」删除

## 模型加载

首次使用发音分析或自动转写时，需要下载模型（合计约 150–300MB）：

| 模型 | 大小 | 用途 |
|---|---|---|
| wav2vec2 音素模型 | 约 100MB | 逐音素对照 |
| Whisper base | 约 210MB | 自动转写 |

下载后会被浏览器缓存，**之后离线可用**。

### 提示下载慢或失败

- 检查网络连接
- 尝试切换到更小的模型
- 若浏览器不支持 WebGPU，会自动使用 CPU 模式，速度较慢但结果一致

## 反馈怎么读

### 朗读短文

| 指标 | 含义 | 怎么提分 |
|---|---|---|
| 读全 % | 参考词被说出的比例 | **这是大头**。先把每个词读全 |
| 读对 % | 读对且无拼写偏离的比例 | 放慢速度，重点练错读词 |
| 语速 | 词/秒 | 保持匀速，别忽快忽慢 |

**漏读会直接标出是哪些词**，这是完整度评分的主要扣分点。

### 情景问答

| 指标 | 含义 |
|---|---|
| 句数 | 说了几句（本题无 7 句门槛） |
| 停顿 | 出现了几次 um / 那个 这类卡壳 |
| 语速 | 词/秒 |

### 话题简述

| 指标 | 含义 | 是否硬门槛 |
|---|---|---|
| **句数** | 要求**至少 7 句** | **是**，不达标直接判定不合格 |
| 要点覆盖 | 话题关键词命中率 | 否，但影响得分 |
| 连接词 | first / also / because 等 | 否，但考察逻辑 |

2025 年起江苏已**取消中文提示**，考试时只显示话题名，
且**禁止出现真实个人信息**（手机号、邮箱、住址），本工具会检测并提醒。

## 常见问题

**Q: 这个分数能预测我中考考多少分吗？**
A: 不能，也刻意不做这个。本工具做的是能力诊断，告诉你离满分别差什么。
正考评分引擎不对外，任何第三方都无法给出可靠估分。

**Q: 为什么我的浏览器很慢？**
A: 未启用 WebGPU 时走 CPU 推理。建议用桌面版 Chrome/Edge，并关闭其他占资源的程序。

**Q: 录音会保存吗？**
A: 不会。音频只在浏览器内存中处理，用完即弃，不上传、不落盘。

**Q: 可以离线用吗？**
A: 可以。模型下载并缓存后，L0/L1/L2 全部分析都能离线运行。
只有 L3（LLM 建议）需要联网，除非你配了本地 Ollama。

**Q: 语料是教材原文吗？**
A: 不是。是依据课标五级与译林版教材话题范围编写的**等效练习材料**，避免版权问题。
