## 裁决原则（先定原则，再逐对套用）

1. **同考点必留一道。** 判为真重复的一对里，保留考点更清晰、材料更自洽的那一道，**另一道换考点重写**。
2. **重写不得降低题数。** 替换题必须同类别、同题数比、同词数上限内。
3. **重写后必须过 topic-guard。** 新题要查过语义闸门，退出码 0 才算完成——这是本轮新增的硬步骤。
4. **换考点不等于换场景。** 若仅换人物换数字而考点不变，仍判重复。

   能、只是事实错 → 甲类；根本不能（如地点短语答 When）→ 丁类。
3. **_COMMON §5.1 裁定「材料算错了」的定级**（R1-B6 提出）：
   按材料算与按正确算**落到不同答案 → 严重**；**落到同一答案 → 中等**。
   严重档的判定标准是「是否破坏判分有效性」，不是「缺陷是否存在」。
