# 任务 prod-C5：产出 C 类批次 C5

## 定位

C 类是听短文答题：每篇 150 到 220 词的短文配 5 道四选一题。
这是中考听力第二大题的主力题型，也是本批要重点防「量级矛盾」的题型。
本批为第 5 批 C 类，编号从 C5-01 到 C5-05。

## 数量与配比（硬性）

- 份数：**5**
- 每份篇数：**5**
- 题目总数：25 题
- 每篇材料正文必须在 150 到 220 词之间（无超无欠）。
- 文件末尾必须有汇总行，写明篇数、题目数、比值、以及本批答案序列。

## C 类专属要求

1. 每篇 5 题必须分别考 5 个**不同**的考点，不得两题考同一句原文的同一个信息点。
2. 至少每篇要有 1 道需要两步推理的题（例如先取数再运算、或先理解让步再得出结论），不能 5 题全是单句直取。
3. 短文里的数字必须能被学生心算还原。如果短文提到重量、金额、时长、人数，必须保证这些数字在物理上和数量级上说得通。历史缺陷教训：写过「一位步行很慢的老人用两只布袋每周搬走 180 公斤」这种量级自相矛盾的句子。
4. 时间线必须闭合。若人物某天缺席跨过整天课程，就要清算整天的课程，不能只算一天。
5. 篇末不得出现露骨的答案提示句。
6. 5 篇的主题不得雷同，且不得与 data/item-bank/C2.md、C3.md、C4.md 的主题重复。

## 格式

严格照抄同类已归档批次的格式：data/item-bank/C2.md。
先读那个文件，模仿它的标题层级、说话人标注方式、选项写法、Answer 行写法、末尾汇总行写法。

## 出题纪律

1. 材料不得出现任何以井号开头的元数据块。文件里只许有材料正文、题干、选项、Answer 行、末尾汇总行。
2. 每个选项都必须在材料里有逐字依据或可反证的依据。不许出现四个选项里三个完全无出处的情形。
3. 标答必须唯一。写完之后逐题逐选项自查一遍：能否把每个错误选项用材料中的一句原文排除。
4. 材料内部必须自洽：时间、人物、称谓、金额、件数前后不能打架。
5. 选项内容不得互相重复，四选一的四项必须互不相同。
6. 全批话轮之间不得雷同。开场白不得都是同一句。
7. 答案字母不得扎堆。全批正确答案要覆盖 A B C D，且不得出现周期性排列。
8. 写文件之前先确认该文件不存在；如果已存在，换名并在总结里说明，不要覆盖。

## 自检（必须在总结里给出实测数字，不得只写合格）

- 每份材料按空白分词的实际词数，逐份列出。
- 题目总数、每份题数、答案序列。
- 每题四选项的逐条依据出处。
- 各字母作为正确答案的次数。

## 输出

写入 data/item-bank/prod/C2.md。
写完后跑一次 pwsh -Command "& docs/pipeline/wordcount-gate.ps1"，把原始输出贴进总结。
