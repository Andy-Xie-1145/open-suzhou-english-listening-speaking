# 任务 V-E3：E3 修复后复核

## 输入

- 被复核文件：data/item-bank/prod/E3.md
- 唯一依据报告：data/item-bank/reviews/R2-E3.md
- 审核规范：data/item-bank/REVIEW-RUBRIC.md

## 执行要求

1. 先做字节级前置校验，写出被修文件与依据报告各自的 MD5、字节数、行数，并做行读取与字节读取的一致性比对。
2. 写出基线对照：依据报告记录的审核前基线 MD5 与当前 MD5 是否不同。相同即代表修复未落盘，必须直接报告不通过。
3. 逐题逐选项判定，不抽样。
4. 必查项按 REVIEW-RUBRIC.md 的 1.7 到 1.10 逐项过，每项都要有实测数字，不得只写 PASS。
5. 独立复算材料里的每一个数字与时间链，不要采信修复方给出的任何数值。
6. 修复方声明的每一项，都要单独列表给出「声明内容 / 你的独立验证结果 / 成立或不成立 / 依据」。若发现未申报的越界改动，必须作为流程问题单独列出。
7. 严禁读取 reviews 目录下任何其他报告、fixes 目录下任何文件。

## E 类专属必查项

- 情景问答：每组 2 题，一问一答，答案必须是可直接朗读的自然口语应答。
- 提问与回答的考点必须不同，不能两题都考同一个语法点。
- 答案必须用材料或题干给出的信息，不得凭空。
- 语速与语调提示（如有）必须与答案的自然重音一致。
- 不得出现中式英语表达，不得出现只有中文才成立的逻辑。

## 输出

写入 data/item-bank/reviews/V-E3.md。
第一节必须是明确结论：通过或不通过，能否放行，严重/中等/轻微各几条。
