# 任务 XOVERLAP：全库跨批次题面重复审计

## 为什么要做这件事

本项目此前只查过**批内重复**（同一批次内的话轮雷同、开场白重复、选项雷同）。
**跨批次的重复从来没查过。**

而项目的目标是「建成**可反复练习**的题库」——
如果 A4-01 的「邻居代收快递」与 A8-03 的「请邻居代喂狗」讲的是同一件事，
学生做第二道时的练习价值就大幅下降。**练习册的重复是最难察觉的一种浪费。**

## 输入

`data/item-bank/` 根目录下的全部批次文件，以及 `data/item-bank/prod/` 下未归档的批次。
共 27 个批次。

## 查什么（三个维度）

### 维度 1 · 场景撞题

提取每个批次的每份材料的**标题**（形如 `## A4-08 邻居帮忙搬箱子`）与情景提示首句，
判断**不同批次之间**是否存在实质相同的生活场景。

**判定标准**：人物关系 + 场所 + 事件三者都相同才算撞题；只共享其中一两项不算。
（例：`邻居代收快递` 与 `邻居代喂狗` —— 人物关系与场景同、事件不同，**不算撞题**；
`菜市场买菜` 与 `菜市场买鱼` —— 三者全同，**算撞题**。）

### 维度 2 · 考点撞题

同一类别内部，不同批次的题目是否反复考同一个能力点与同一组素材？
例如 B 类反复出现「购物比价算总价」，A 类反复出现「约时间」。

**这不必然是缺陷**——中考听力就是要覆盖常见场景。
但若**同一类别内超过一半的批次**都在考同一个考点，就应当指出。

### 维度 3 · 素材撞题

不同批次的材料里是否出现了**同一批人名**（Jack 出现了几次？）、
**同一组数字**（45 元、7:30、Room 302 这类具体值反复出现）、
**同一句话**（逐字重复的句子）。

**逐字重复是最严重的一种**，请单独列出。

## 怎么查

- **全部自己跑脚本**，不要手工翻 27 个文件。
- 人名与数字可以用正则批量提取后统计频次。
- 标题与情景提示可以提取后两两比对。
- **Jaccard 相似度**：把每份材料归一化后算两两相似，报告最高的若干对与命中数（阈值 0.6）。

## 注意

- **`C3.meta.md` 是旁挂文件，不是批次，排除。**
- **`REVIEW-RUBRIC.md` 与 `INDEX.md` 不是题目文件，排除。**
- E 类材料是中文情景提示，与其他类别的比对方式不同，**分开查**。
- 门禁脚本会读 reviews/，属机械比对，允许运行；**但不要人工阅读 reviews/ 与 fixes/ 下的任何报告**。

## 输出

写入 `docs/pipeline/cross-overlap-audit.md`，包含：
1. **三个维度各自的结论**，每条结论都要给出可核对的清单（哪几个批次、哪几份材料）；
2. 逐字重复的句子清单（若有），逐条给出位置；
3. 人名与高频数字的跨批次分布表；
4. Jaccard 最高的对与命中数；
5. **明确的建议清单**：哪些是必须处理的、哪些是可接受的、哪些只是记录。

> **不要为了让报告好看而少报，也不要为了显得严格而多报。**
> 每一条都要能被另一个审核员按你的清单逐条核对。
> **「重复」本身不是缺陷**——中考听力必然重复场景。**缺陷是「同一道题被抄了两遍」或「整库缺某个高频场景」。**

完成后用不超过 250 字的中文总结回复：三个维度各自的结论、逐字重复有无、最需要处理的三条、以及任何你发现与任务书描述不符之处。
