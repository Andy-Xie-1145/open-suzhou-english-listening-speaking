# 任务 prod-B7：产出 B 类批次 B7

## 定位

B 类是「一个对话两道题」：每段较长对话配 2 道四选一题，两题都必须能只靠这段对话答出。

- 类别：B 类
- 编号：B7-01 到 B7-08，连续无缺号无重号
- 数量：8 份材料
- 题数比：每份材料 2 道题，全批 16 道题

## ⚠ 必做：语义查重闸门（读 `docs/pipeline/TOPIC-GUARD.md`）

**标题查重已经证明不够用。** 上一轮 8 个出题员并发时，各自只对着**出题前**的标题清单避撞，
互相看不见对方正在写什么，结果 A11-01「空调设成二十六度」与 A16-02「空调要开多少度」
同时产出——字面不同，**却是同一考点**。字面标题、词袋签名、问句主干三种口径都查不出这一对。

**所以你必须用语义索引自查，步骤不可省：**

1. 先把 15 个候选题的「标题 + 材料 + 题干」写成一行一条的临时文件，例如 `data/item-bank/prod/.cand-xx.txt`。
2. 跑：`$env:HF_HUB_OFFLINE='1'; python scripts/topic-guard.py check data/item-bank/prod/.cand-xx.txt`
3. **退出码 1 就是有超阈值相似项**：必须换题，重查，**直到退出码 0 才允许写文件**。
4. 逐条读回 top-3，**自己判断是不是同一考点**——脚本只报相似度，0.78 的「学吉他／吉他课」是真重复，
   0.85 的「去博物馆的公交／周六坐公交」不是。**阈值之上不等于重复，但你不看就等于没查。**
5. 写完文件、跑完 wordcount-gate 之后，跑一次 `python scripts/topic-guard.py build` 把本批并进索引。
   **不 build，下一批就查不到这一批。**

清理：临时候选文件在批次完成后删掉，不要留在仓库里。

## 出题纪律

1. **每个选项都必须能在材料里找到逐字依据或可反证的依据。** 若某题有两个以上选项在材料中完全查无出处，判**严重**。
   干扰项优先用「改变数字 / 改变星期 / 改变时刻 / 改变人称 / 改变地点」这几类，因为它们都能在材料里找到反证。
2. **材料内部必须自洽**：时间、人物、称谓、金额、件数前后不能打架。
   凡出现数字必须能被心算还原，且量级站得住。凡出现时长或时刻必须重算一遍时间链。
3. **标答必须唯一**：逐题自查「能否用材料中的一句原文排除其余选项」。
4. **答案字母不得扎堆**：覆盖 A B C D（D 类覆盖 A B C D E）；周期检测覆盖**所有不超过序列长度一半的周期**；不得连续 3 个相同；不得有全批一次都不作答案的字母。
5. **开场白归一化去重**：剥离说话人标注、去标点、转小写、取前 6 词作 key，key 必须互不相同。
6. 题目文件内**禁止**任何逐题逐份的过程记录区块、角色方向自检表、考点对照表。
   **但允许**：文件开头的一级标题批次说明行、`>` 出处块、每份材料的 `## B7-xx 标题` 行。
7. 材料必须写明是**仿写素材，非真题**；若本型结构无官方依据，在文件头注明。

## 自检（总结里必须给实测数字，不许写「已检查」）

- 8 份材料逐份词数（空白分词，上限见上），标出余量最小的三份；
- 答案序列、字母计数、周期检测（覆盖所有不超过半长的周期）、最长连号、逐题位置偏斜；
- 开场白归一化去重实测结果：key 重复数必须为 0；
- 每题各选项的逐条依据出处；
- 主题分布说明。
