# 轻量结构复核口径（用于无法字节级判定的早期批次）

## 为什么需要这个

第 36 轮的 `check-integrity.ps1` 判出一批早期批次为 `UNVERIFIED`——它们的 V 报告写于字节级校验被写进规约之前，
报告里没有 MD5 记录，因此**在字节层面永远无法回溯判定该报告对当前文件是否仍然成立**。

这些批次的题目文件修改时间又比报告晚 30 到 70 秒，因此列为待销案。

**本任务不是全量重审。** 全量重审会把已经审过五遍的批次再审五遍，成本远大于收益。
本任务只回答一个问题：**这个批次的结构与内部一致性是否完好，即它是否还「能用」。**

## 五项必查（逐批做，缺一不可）

**1. 答案序列自洽（按类别分别处理，不要套错格式）**

本库五类的答案写法**互不相同**，第 35 轮之前我曾把它们一律对待，导致脚本判错 9 个批次。**先确认类别再动手。**

| 类别 | 答案行长什么样 | 末尾有没有汇总行 |
|---|---|---|
| A / B / C | 每题一行 `**Answer** X` | **早期批次没有汇总行**（A-batch0、A1、A2、A3、A4、A5、B-batch1、C-batch1 均无）；较新批次有，形如 `本批答案序列：C B D A C ...` |
| D | 一行 `**Answers**`，**答案写在它的下一行**，形如 `① A　② D　③ B` | D 类惯例没有汇总行 |
| E | **没有 Answer 行**。答案要求写在 `**考点**` 里（例如「答语用过去式完整句并把问句的 you 换成 he」） | 没有汇总行 |

因此：
- **A/B/C 且有汇总行** -> 逐题 Answer 拼出的序列必须与汇总行逐位相同。
- **A/B/C 无汇总行** -> 退化为两项：(a) Answer 行数必须等于预期题数；(b) 答案字母分布不得退化（例如 15 题里某个字母出现 10 次以上，判缺陷）。**不要报告「无法比对」，那是你的格式判断错了。**
- **D** -> 每份的 `**Answers**` 下一行必须有 3 个槽位答案；全批合计 30 个槽位。
- **E** -> 每题必须有 `**考点**` 行，且考点里要写明该题的人称指向（谁问、谁答）。若考点缺失或人称未指明，判缺陷。

**此外，A/B/C/D 四类都要做这三项答案分布检查**（第 40 轮补：RECHECK-G2 指出 D-SPEC 要求查周期性，
而本文件的五项里漏了它）：
1. **周期性**：全卷答案序列是否存在周期 p=2 到 6。**只接受至少可比较 2 对的周期**（序列长度 n 时要求 p ≤ n−2），
   否则短序列会因比较对数为 0 而空真误报。
2. **最长连续相同**：要求不大于 2。
3. **字母覆盖**：A 到 D（D 类为 A 到 E）不得有**全卷一次都不作答案**的字母——那是固定陷阱。

这三项任何一项不合格即为缺陷。**报告里要写出实测数字，不要只写 PASS 或不适用。**

**2. 题数比**
A 类：题数 ÷ 段数 = 1。B 类：题数 ÷ 段数 = 2。C 类：题数 ÷ 篇数 = 5。E 类：题数 ÷ 组数 = 2。
D 类：空数 ÷ 份数 = 3。
编号必须连续、无缺号、无重号。

**3. 词数复算**
用空白分词、只数材料正文（含说话人标注；D 类剔除表格标记），上限：A 60、B 200、C 150 到 220、D 200。
把每段的实测词数列成表。任一段越限即为严重缺陷。

**4. 抽查答案唯一性**
本类别**抽查 3 道题**（优先选材料最长、算术最复杂的那三段）。
逐选项代入：标答是否唯一，其余三个选项能否各自被材料中的一句话排除。
若抽查中发现答案不唯一或材料自相矛盾，**必须把那一份的全部题目补审**，不能只报抽查结论。

**5. 格式**
以井号开头的行只有两种允许：批次开头的一级标题说明行、`>` 出处块；每份材料的 `##` 编号标题行。
除此之外出现逐题逐份的过程记录区块即为缺陷。

## 结论口径（只有三种，不许写别的）

- **结构完好，可销案** —— 五项全过。
- **发现缺陷 N 条** —— 列出每一条的位置、原文、为什么是问题、定级。
- **无法判定** —— 明确写清是哪一项做不了、为什么。

**不许因为「之前审过」就跳过任何一项。**

## 输出

每个批次写一节，节标题为 `## <批次名>`，末尾附一张五项打勾的表。
**不要写长篇大论的重新审核**，你是在做结构销案，不是在做第二轮审核。
