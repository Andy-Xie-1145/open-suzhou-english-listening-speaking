**2. 被改的那一篇，新题干是否成立？**

**3. 25 题逐题逐选项判定**，100 个选项全部实读，不抽样。

**4. 考点分类重数**：逐篇标注每题属事实 / 推断 / 主旨哪一类，给出全卷推断题总数。
**自己数，不许引用 R1 或 R2 的数。**

最长连续相同、四字母覆盖、逐题位置偏斜。

**7. 常规**：题数比 25÷5=5；编号连续；跨篇雷同（Jaccard 阈值 0.6）；材料数字逐个重算；
篇末是否为中性叙述句而非答案提示句；跑三个闸门并贴原始输出。
