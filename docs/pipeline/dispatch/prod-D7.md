- 类别：D 类
- 编号：D7-01 到 D7-10，连续无缺号无重号
- 数量：10 份材料
- 题数比：每份材料 3 道题，全批 30 道题

## 出题纪律

1. **每个选项都必须能在材料里找到逐字依据或可反证的依据。** 若某题有两个以上选项在材料中完全查无出处，判**严重**。
   干扰项优先用「改变数字 / 改变星期 / 改变时刻 / 改变人称 / 改变地点」这几类，因为它们都能在材料里找到反证。
2. **材料内部必须自洽**：时间、人物、称谓、金额、件数前后不能打架。
   凡出现数字必须能被心算还原，且量级站得住。凡出现时长或时刻必须重算一遍时间链。
3. **标答必须唯一**：逐题自查「能否用材料中的一句原文排除其余选项」。
4. **答案字母不得扎堆**：覆盖 A B C D（D 类覆盖 A B C D E）；周期检测覆盖**所有不超过序列长度一半的周期**；不得连续 3 个相同；不得有全批一次都不作答案的字母。
5. **开场白归一化去重**：剥离说话人标注、去标点、转小写、取前 6 词作 key，key 必须互不相同。
6. 题目文件内**禁止**任何逐题逐份的过程记录区块、角色方向自检表、考点对照表。
   **但允许**：文件开头的一级标题批次说明行、`>` 出处块、每份材料的 `## D7-xx 标题` 行。
7. 材料必须写明是**仿写素材，非真题**；若本型结构无官方依据，在文件头注明。

## 自检（总结里必须给实测数字，不许写「已检查」）

- 10 份材料逐份词数（空白分词，上限见上），标出余量最小的三份；
- 答案序列、字母计数、周期检测（覆盖所有不超过半长的周期）、最长连号、逐题位置偏斜；
- 开场白归一化去重实测结果：key 重复数必须为 0；
- 每题各选项的逐条依据出处；
- 主题分布说明。
