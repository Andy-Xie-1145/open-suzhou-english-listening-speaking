# 任务 R2-C4：C 类批次第二轮独立审核

## 输入

- 被审文件：data/item-bank/prod/C4.md（C 类短文，5 篇 25 题）
- 审核规范：data/item-bank/REVIEW-RUBRIC.md
- 该批次已完成 R1 与 F1，但**从未经过第二轮审核**。本轮是首轮之外的第二次独立审核。

## 执行要求

1. 先做字节级前置校验，报告开头给出 MD5 与字节数。
2. 逐题逐选项判定 25 题，不得抽样。已复核题号清单必须列全 25 行。
3. 必查项按 REVIEW-RUBRIC.md 的 1.7 到 1.10 逐项过：重复、词数、答案位置排列、位置偏斜与键位覆盖、槽位算术、题数比、词数口径。
4. C 类专属：每篇 5 题，题数比 5 比 1 必须成立；材料 150 到 220 词。
5. 特别核查：本批次经历过一次 F1 修复，请确认修复没有引入新缺陷，也没有改动任何答案。
6. 严禁读取 reviews 目录下任何其他报告、fixes 目录下任何文件。
7. 不要为了凑缺陷而放宽标准，也不要为了显得严格而制造缺陷。每一条缺陷都必须能被原文逐字反证。

## 输出

写入 data/item-bank/reviews/R2-C4.md，格式见 REVIEW-RUBRIC.md 第 3 节。
第一节必须是明确结论：是否通过、能否放行、缺陷计数、是否需返工。
